# Open Questions

> Агент дописує нові записи в кінець без підтвердження.
> Редагування або видалення наявних записів — тільки з підтвердження власника.
> Нумерація наскрізна і не перевикористовується.

Формат:

```
## OQ-XXX — <коротке формулювання>
**Відкрито:** YYYY-MM-DD
**Джерело:** BA / Architecture / Slice SLICE-00X / Session
**Блокує:** FR-012, SLICE-004 (або «не блокує»)
**Питання:**
**Варіанти / гіпотези:**
**Статус:** OPEN | ANSWERED | DEFERRED
**Відповідь:**
**Закрито:** YYYY-MM-DD
```
